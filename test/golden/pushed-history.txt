      → These names are normally used for logins or API tokens, and they were pushed. Rotate anything that was real, then see "What to do next" below.
  ✔ No data files in git history

  What to do next
    1. Rotate or revoke these now: service-account-prod.json.
       They were pushed, so cleaning history will not un-leak them from clones, forks or caches.
    2. Remove service-account-prod.json from history yourself — pushready will not do it for you:
       git filter-repo --invert-paths --path "service-account-prod.json"
       git filter-repo is not part of git; install it first.
       Run it on a fresh clone. It refuses to rewrite a repo with other changes unless you pass --force,
       and it removes the "origin" remote afterwards, so add it back before pushing.
    3. Force-push the rewritten history, and ask every collaborator to re-clone.
       Old clones and forks still hold the secret; a rewrite on your side does not reach them.
       On GitHub, cached pull request refs can keep the old commits reachable even after a force-push.
       Contact GitHub Support to have them purged: https://support.github.com/
